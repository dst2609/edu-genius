# edu-genius

Edu Genius a Full Stack web application that is based on MERN Stack.

## Getting Started

`git clone git@github.com:dst2609/edu-genius.git`

`cd edu-genius/edu-genius-api`

`npm install`

`npm start` [Backend is up and running]

--Open new terminal tab

`cd edu-genius/edu-genius-ui`

`npm install`

`npm run dev` [Frontend is up and running at http://localhost:5173/]
